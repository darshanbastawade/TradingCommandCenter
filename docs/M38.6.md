# M38.6 — Authoritative exchange calendar for execution risk

M38.6 makes the M16.1 exchange-session calendar the single deterministic calendar truth for research and M18 execution risk. The immutable Domain calendar exposes trading-date/session lookup, exchange-local conversion and a canonical SHA-256 over timezone, normal hours, holidays and special sessions.

M18 no longer assumes Saturday and Sunday alone determine closure. It requires an explicit calendar input. Entry is permitted only in the intersection of the exchange session and configured risk-policy entry window. Entry start is inclusive; the last-entry and session-close boundaries are exclusive. Planned exit must be later on the same exchange-local date and cannot exceed either the policy mandatory-exit time or the actual session close.

This supports weekday holidays, declared Budget Saturdays, Muhurat sessions and early closes. For the committed 2025 fixture, the 2025-10-21 Muhurat session is 13:45–14:45, so 09:15 is rejected, 13:45 is accepted, and an exit after 14:45 is rejected.

Every schema-v2 `RiskDecision` records `CalendarId` and `CalendarSha256`; both are bound into its decision fingerprint. Changing an exchange rule or calendar identity changes the decision hash. The final sized-decision hash continues to bind the policy decision, prices and whole-lot result.

The API composition root loads `ExchangeCalendar` from committed configuration and a local calendar file before `evaluate-risk`, paper trading or live-order preparation. Calendar loading performs no network call. Missing, malformed or contradictory calendar data fails closed before M18 can approve an order.

Legacy M18-containing artifacts remain JSON-readable. New M18 evaluations use schema version 2 and carry calendar evidence.

No database schema or migration is required for M38.6.
