# M12 — Point-in-time regime classification

M12 adds deterministic regime snapshots for every candle. The classifier labels three independent dimensions:

- Trend: `Bullish`, `Bearish`, `Sideways`, or `Unknown`, using fast/slow EMA alignment plus a minimum ADX.
- Volatility: `Low`, `Normal`, `High`, or `Unknown`, comparing current ATR with an average of prior ATR observations only.
- Opening gap: `GapUp`, `GapDown`, `Normal`, or `Unknown`, comparing the session open with the last observed close of the prior session.

Warm-up values remain `Unknown`. Each output has the same timestamp as its input candle, and no label reads a later candle. `RegimePerformanceAnalyzer` joins regimes to trades by signal timestamp and reports trades, winners, net P&L, win rate and average net R for every populated label.

These are mechanical labels, not predictions. Expiry-day and multi-timeframe morning-structure labels require calendar and higher-timeframe data that the current market-data model does not yet store.

M12 adds no database table, migration, external call or execution authority.
