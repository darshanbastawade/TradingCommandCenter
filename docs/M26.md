# M26 — vectorbt Research Worker

M26 adds an out-of-process Python research worker for fast parameter screening. Its declared role is `researchExploration`: its results can propose candidates but cannot qualify a strategy, issue a certificate or replace the authoritative native C# engine.

## Local setup

Python 3.11–3.14 is required. This machine has Python 3.13. The worker pins `vectorbt==1.1.0` in `workers/vectorbt/requirements.txt`; [PyPI lists that release](https://pypi.org/project/vectorbt/1.1.0/) as compatible with Python 3.13.

```powershell
$vectorbtVenv = Join-Path $env:LOCALAPPDATA "TradingCommandCenter/vectorbt-venv"
python -m venv $vectorbtVenv
& "$vectorbtVenv/Scripts/python.exe" -m pip install -r workers/vectorbt/requirements.lock.txt
dotnet user-secrets set "VectorbtWorker:PythonExecutable" `
  "$vectorbtVenv/Scripts/python.exe" --project src/Trading.Api
```

The short virtual-environment path avoids legacy Windows path-length failures in Jupyter dependencies. `requirements.lock.txt` records the smoke-tested Python 3.13/Windows dependency set; `requirements.txt` records the direct constraints, including Plotly below 7 because vectorbt 1.1.0 still registers a template removed by Plotly 7. The worker receives JSON through one temporary input file, writes one bounded output file, uses no shell invocation and has a ten-minute default timeout. It accepts at most 10,000 candidates and 1,000,000 chronological candles.

## Research semantics

The worker calculates vectorized EMA, ATR, ADX, VWAP, volume and strategy-specific screening signals for the five native strategies. Signals shift by one row before entry, session exits are explicit, and vectorbt applies exploratory stop/target, slippage and portfolio calculations.

These calculations are intentionally screening approximations. They do not reproduce every native fill, cost, whole-lot sizing or ignored-candidate rule. Each result is therefore labeled `researchExploration` and bound to the request and evidence hashes. M28 independently reruns selected candidates using native C#.

M26 makes no broker, Azure OpenAI or Azure-hosting call.
