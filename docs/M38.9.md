# M38.9 — Real LEAN validation closure

M38.9 adds `external/lean/TradingCommandCenterLean`, a separately maintained QuantConnect LEAN Python project for `vwap-ema-trend-breakout-v1`. It reads the schema-v2 M29 `request.json` and `candles.csv` package selected by `tccRunId`. It does not import, reference or call native C# strategy code.

The implementation independently calculates EMA, Wilder ATR/ADX/+DI/-DI, previous rolling volume and exchange-session VWAP, then applies the complete strategy and deterministic execution rules. Its fills are submitted through LEAN with explicit fill price/time evidence so official closed trades can be reconciled with the portable M25 run.

The adapter requires an immutable `quantconnect/lean@sha256:<digest>` image. It verifies the algorithm source against `tcc-strategy-manifest.json`, hashes the request and CSV package, accepts official `TotalPerformance.ClosedTrades`, and binds the official result hash, image, algorithm revision, implementation version and `tccRunId` into the sealed run. M30 carries this provenance. M32 rejects missing provenance even if comparison metrics pass.

The original M30 tolerances remain unchanged. The deterministic two-session fixture produces both directions and passes strict native/independent implementation comparison. The other four strategies remain unsupported and fail closed.
