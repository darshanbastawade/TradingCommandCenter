# M17 — Real options back-testing

M17 executes underlying strategy signals against observed option bid/ask data. It never converts an index move into assumed option profit and never manufactures a premium with Black–Scholes. The stored premium already reflects the market's realized delta, theta and implied-volatility effects.

## Database

Apply the `OptionContracts` and `OptionQuotes` migration explicitly:

```powershell
dotnet run --project src/Trading.Api -- database-update
```

The equivalent idempotent SSMS script is [sql/M17-Real-Options.sql](sql/M17-Real-Options.sql). Application startup does not migrate the database.

## Load contracts and quotes

Register every contract whose historical quotes will be imported. `right` accepts `Call` or `Put`; expiry uses `yyyy-MM-dd`.

```powershell
dotnet run --project src/Trading.Api -- add-option-contract `
  --contract-id 11111111-1111-1111-1111-111111111111 `
  --underlying-id YOUR-REGISTERED-UNDERLYING-GUID `
  --exchange NFO `
  --symbol NIFTY26SEP25000CE `
  --expiry 2026-09-24 `
  --strike 25000 `
  --right Call `
  --lot-size 65 `
  --tick-size 0.05
```

Import one contract per CSV. The exact header is:

```text
timestamp,bid,ask,last,volume,openInterest
```

Timestamps require `Z` or an explicit offset, rows must be chronological, prices must be positive and on tick, ask must be at least bid, and volume/open interest cannot be negative. Imports are capped at 10,000 rows and 4 MiB, reject overlaps, and commit atomically. See [../samples/option-quotes.csv](../samples/option-quotes.csv).

```powershell
dotnet run --project src/Trading.Api -- import-option-quotes `
  --contract-id 11111111-1111-1111-1111-111111111111 `
  --file .\data\NIFTY26SEP25000CE.csv
```

## Run an options backtest

```powershell
dotnet run --project src/Trading.Api -- run-options-backtest `
  --underlying-id YOUR-REGISTERED-UNDERLYING-GUID `
  --timeframe 5 `
  --from 2026-01-01T09:15:00+05:30 `
  --to 2026-07-01T09:15:00+05:30 `
  --strategy-id vwap-ema-trend-breakout-v1 `
  --initial-capital 100000 `
  --allowed-risk 750 `
  --maximum-capital 100000 `
  --maximum-lots 5 `
  --premium-stop-percent 0.20 `
  --reward-risk 3 `
  --minimum-volume 1000 `
  --minimum-open-interest 5000 `
  --maximum-spread-bps 300 `
  --slippage-bps 5 `
  --cost-profile zerodha-nse-equity-options-2026-04-01 `
  --session-exit 15:25 `
  --output .\artifacts\m17-options.json
```

`--maximum-lots` and `--session-exit` are optional. The cost profile accepts the dated Zerodha/NSE equity-options profile or the explicit research value `none`.

For a bullish underlying signal the selector buys a Call; for a bearish signal it buys a Put. It chooses the nearest non-expired expiry and exactly one available strike in the money: the highest strike below the underlying entry for a Call, or the lowest strike above it for a Put. It does not silently fall back to another strike or expiry when data or liquidity is missing.

Entry occurs on the next underlying bar using the observed ask plus adverse slippage, rounded up to tick. Exits inspect later observed bids at quote timestamps. Stop, target, session and end-of-data exits use the bid minus adverse slippage, rounded down to tick. Premium stops and targets are calculated from the executed premium; position size uses rupee risk, contract lot size, capital cap and optional lot cap. Brokerage, STT, exchange/IPFT, SEBI, GST and stamp duty use the dated M6 options profile.

The JSON artifact records the exact contract, expiry, strike, underlying direction, bid/ask inputs, spread, fills, initial rupee risk, net R multiple, costs, aggregate wins/losses/net R, rejected-candidate reasons, settings, and a SHA-256 over all consumed underlying candles, contracts and option quotes.

## Boundaries

Quote timestamps are discrete observations. M17 only detects stop or target crossings at an observed bid and cannot reconstruct intrabar order-book events between samples. Volume is the supplied quote-row value, typically the exchange's cumulative contract volume. Contract histories must include expired instruments; a current broker instrument dump alone is insufficient. M17 does not estimate Greeks, interpolate missing quotes, roll a position, hold overnight, place orders, or claim out-of-sample validity by itself. Use M16 discipline when comparing option results.
