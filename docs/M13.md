# M13 — Parameter robustness

M13 evaluates a declared neighborhood around one baseline parameter set. `ParameterNeighborhood.Cartesian` creates a deterministic Cartesian grid with unique IDs and exactly one declared baseline. Both the builder and analyzer enforce a hard maximum of 500 scenarios.

For every scenario, `ParameterRobustnessAnalyzer` records the complete M7 metrics and expectancy change from baseline. Its summary contains:

- profitable-scenario rate;
- rate within the configured baseline-expectancy degradation limit;
- worst, median and best expectancy;
- stability score: 50% profitable-scenario rate plus 50% acceptable-degradation rate.

The engine reports all scenarios and does not select the best one. A caller must evaluate the grid on a previously declared validation set and must not repeatedly redesign the grid from those results. Null expectancy fails the degradation check rather than being converted to zero.

M13 adds no optimizer, database table, migration, external call or execution authority.
