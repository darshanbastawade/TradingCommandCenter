# M33 — Astra Research Analyst V2

M33 gives Astra the complete V2 evidence package: M32 certificate, M16 research artifact, M30 comparison and M31 robustness suite. It verifies all hashes and identities locally before making a request.

```powershell
dotnet run --project src/Trading.Api -- analyze-research-v2 `
  --certificate .\artifacts\strategy-certificate-v2.json `
  --research .\artifacts\research-integrity.json `
  --comparison .\artifacts\cross-engine-comparison.json `
  --robustness .\artifacts\robustness-suite.json `
  --output .\artifacts\astra-research-analysis-v2.json
```

Use the existing `AzureOpenAI` User Secrets or environment variables. The deployment should point to GPT-6 Astra. The implementation uses the Responses API, strict Structured Outputs, `store: false`, and no model tools. GPT-6 Astra supports the Responses endpoint and Structured Outputs according to the [official model documentation](https://developers.openai.com/api/docs/models/gpt-6-astra); the [Responses API reference](https://developers.openai.com/api/reference/cli/resources/responses/methods/create) documents `instructions`, `store`, text output configuration and tool omission.

The V2 response must echo the exact certificate and strategy identities and provide research, cross-engine and robustness findings, qualification caveats, next tests, warnings and one advisory recommendation: `qualificationReview`, `moreResearch` or `reject`. The prompt treats all embedded artifact text as untrusted data and prohibits recalculating or changing deterministic evidence, rankings, certificate gates, risk or trading authority.

The output binds the certificate hash, canonical evidence-bundle hash, deployment, returned model, provider response ID, prompt version/hash, token counts and structured response. `deterministicQualificationChanged` is always false and is enforced by the artifact codec. Astra's recommendation is recorded by M34 but is never a qualification gate.

M33 creates an immutable local JSON artifact and no SQL row. It makes one paid Azure OpenAI call when explicitly invoked, but enables no web search, file search, code execution, functions or other tools. It places no broker order.
