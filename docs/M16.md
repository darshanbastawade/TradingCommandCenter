# M16 — Research integrity closure

M16 closes the research pipeline around the five implemented strategy hypotheses. A completed run now starts with a certified candle set, evaluates every strategy under the same declared settings, records robustness and adverse execution evidence, ranks the comparable results, and persists the exact JSON artifact with cryptographic hashes.

## Apply the database migration

The local `Market` database needs the `ResearchRuns` table. The CLI reads the same ignored `appsettings.Local.json` connection as the API and does not print credentials:

```powershell
dotnet run --project src/Trading.Api -- database-update
```

The command is explicit; application startup never changes the schema. An idempotent SSMS alternative is [sql/M16-Research-Integrity.sql](sql/M16-Research-Integrity.sql).

## Prepare the calendar

Create a UTF-8 text file containing one NSE holiday per line in `yyyy-MM-dd` form. Blank lines and lines beginning with `#` are ignored. The file must declare every weekday closure in the requested period. Normal weekends are excluded automatically.

```text
# NSE full-day holidays for the chosen period
2026-10-02
```

The certificate expects one bar at every timeframe boundary from 09:15 inclusive through 15:30 exclusive in India Standard Time. It rejects missing, duplicate, out-of-session, holiday, and unexpected bars before any strategy is evaluated.

## Run the complete research workflow

Run from the repository root, replacing the example identity and dates with data registered in `Market`:

```powershell
dotnet run --project src/Trading.Api -- run-research `
  --instrument-id 00000000-0000-0000-0000-000000000000 `
  --timeframe 5 `
  --from-session 2025-01-01 `
  --to-session-exclusive 2026-01-01 `
  --training-sessions 60 `
  --testing-sessions 20 `
  --embargo-sessions 1 `
  --training-mode rolling `
  --initial-capital 100000 `
  --allowed-risk 750 `
  --maximum-capital 100000 `
  --maximum-lots 5 `
  --slippage-bps 5 `
  --cost-profile zerodha-nse-equity-options-2026-04-01 `
  --source-revision research-plan-v1 `
  --data-source YOUR_VENDOR `
  --data-version YOUR_IMMUTABLE_EXPORT_ID `
  --calendar-id nse-2026-v1 `
  --holiday-file .\data\nse-holidays-2026.txt `
  --output .\artifacts\research-run-001.json
```

`--training-mode` accepts `rolling` or `anchored`. `--cost-profile` accepts `none`, `zerodha-nse-equity-intraday-2026-03-01`, or `zerodha-nse-equity-options-2026-04-01`. `--maximum-lots` is optional. The output directory and holiday file must already exist, and an existing output file is never overwritten.

## Evidence recorded

The artifact contains the source revision, exact configuration, configurable ranking weights and scales, dataset certificate and SHA-256, and evidence for all five strategies. Each strategy includes one chronological holdout, walk-forward folds, a declared three-point primary-parameter neighborhood, point-in-time regime performance, results after removing the best 1%, 3%, and 5% of trades, and baseline/adverse slippage and fixed-cost scenarios. The final ranking still applies hard qualification gates and can select zero, one, or two strategies.

The artifact is written atomically. The database stores its exact JSON plus dataset, configuration, and artifact SHA-256 values. A unique database index rejects a repeated dataset/configuration/source-revision experiment. If persistence fails, the newly written file is removed.

Saved metadata is available at `GET /api/reports`; `GET /api/reports/{id}` returns the exact immutable artifact. `/health/ready` now also verifies that `ResearchRuns` is queryable and that no migrations are pending.

## Boundaries

M16 provides research evidence and reproducibility controls. It does not claim statistical significance, guarantee profitability, select option contracts, authorize orders, connect a broker, call Azure OpenAI, or add Azure hosting. A source revision is operator-supplied because this repository has no commit yet; use a Git commit SHA once the code is committed.
