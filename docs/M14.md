# M14 — Strategies 2–5

M14 adds four differentiated, deterministic intraday research hypotheses alongside `vwap-ema-trend-breakout-v1`:

1. `opening-range-breakout-v1` — closes outside the current session's first configured bars with volume confirmation.
2. `ema-pullback-continuation-v1` — a pullback touches the fast EMA and the next bar resumes an EMA/VWAP/ADX-aligned trend.
3. `vwap-reclaim-rejection-v1` — price crosses back through session VWAP in the direction of the EMA trend.
4. `adx-trend-continuation-v1` — rising ADX, directional-index agreement and a break of the prior bar continue the trend.

`StrategyCatalog.CreateDefaults()` returns all five hypotheses with stable IDs. Every strategy uses completed candles, exchange-local session boundaries, explicit entry windows, ATR stops and a default 3R target. Candidates retain numerical evidence and have no order-routing authority.

The existing `run-oos` and `run-walk-forward` SQL commands accept any catalog ID through optional `--strategy-id`; omitting it preserves strategy #1 as the default.

The strategies currently evaluate one stored timeframe and the traded candle instrument. Higher-timeframe confirmation and actual option-contract selection remain future work. Defaults are hypotheses and must pass M10–M13 validation before qualification.

M14 adds no database table, migration, external call or execution authority.
