# M36 — Live Reconciliation

M36 has two explicit modes. Production reconciliation is broker-backed and durable-ledger-backed. File reconciliation is retained for diagnostics only.

## Production command

```powershell
dotnet run --project src/Trading.Api -- reconcile-live `
  --paper-qualification .\artifacts\paper-qualification.json `
  --output .\artifacts\live-reconciliation.json
```

Production M36 requires schema-v2 M35 evidence. It obtains fresh Zerodha profile, equity margin, net-position, and day-order data directly from the broker adapter. `Zerodha:UserId` must match the profile response. Expected cash, positions, realized P&L, and order/fill state come from the latest verified `InternalTradingLedgerSnapshot`, then every internal order is cross-checked with the persisted M23 record and broker receipt.

The committed maximum age is 30 seconds for both broker and internal state. Missing, stale, invalid, unresolved, account-mismatched, or unmappable state fails before eligibility. Cash tolerance is configuration-owned and defaults to ₹1.

The schema-v2 result binds source mode, broker provider/account, broker snapshot SHA-256, internal ledger SHA-256, and internal revision. A reconciled authoritative result is the only M36 evidence that can enter M37 `DirectLive` evaluation.

## Diagnostic command

[live-reconciliation.json](../samples/live-reconciliation.json) remains useful for deterministic diagnostics:

```powershell
dotnet run --project src/Trading.Api -- reconcile-live-file `
  --paper-qualification .\artifacts\paper-qualification.json `
  --file .\samples\live-reconciliation.json `
  --output .\artifacts\diagnostic-reconciliation.json
```

Even an exact diagnostic comparison has `eligibleForControlledAutomation: false`. M37 rejects it for direct-live authorization.

Any authoritative difference produces a sealed `divergent` artifact and exit code 4. M36 performs read-only Zerodha calls and never places, modifies, or cancels an order. See [M38.5](M38.5.md) for persistence and current ingestion boundaries.
